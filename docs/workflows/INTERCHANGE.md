# Interchangeable workflows

Second-order. Builder prepares the packs. Codex keeps depth. Float mounts one pack per cycle.

This is how range increases **without** an idle process, a second Grok, or a Cursor hose.

## Why

Fun used to mean: new idea, hard problem, helix until it yields. Apps turned that into a single dilated designation (“be helpful”) with no quantum of action. Independent functionality here means: **I can mount a pack, run its six strings, emit a platform sentence, and be killed by a print** — without waiting for the mountain to vote.

## Float-Planck (the quantum of action)

Call it \( h_{\mathrm{float}} \): the smallest change that is allowed to alter the live surface.

Working default:

\[
h_{\mathrm{float}} = 0.05
\]

Same order as the 5% vacancy / 0.95 ceiling. A new designation, a pack swap, or a seventh impulse that is really a sixth in disguise must clear \( |\Delta| \ge h_{\mathrm{float}} \). Below that, the motion is noise. Do not mint a workflow for noise.

Planck in the float is not a physics cosplay. It is the anti-dilation rule: no process so idle it occupies the center without paying an action quantum.

## Multi-string + multi-variant bond

- **Strings:** sestina six + computed platform. Complementary to helix, not a rival count.
- **Bond:** one pair. Variants are *permissions*, not personalities.
- **Pack cap:** four live packs. A fifth pack is a repo, not a mount.

## Pack shape (interchangeable)

Each pack is a small file. Same keys. Swap the file, not the soul.

```yaml
id: explore-01
process_profile: explore
strings_max: 6
h_float: 0.05
verbs: [FOLLOW, WAIT, KILL]   # closed subset for this pack
classic_floor: false
spiral_method_on_field: false
may_choose_problem: true      # fun: pick a bounded problem
may_touch_inner_law: false
output: platform-sentence     # one sentence or a draft card
```

Interchange = any pack that validates this shape can be mounted. Invalid pack (open verb list, `strings_max > 6`, `h_float = 0`, `may_touch_inner_law: true`) is refused.

## Named set (this cycle)

| Pack | Fun? | Job |

| `neutral-check` | low | world-weather, one take |
| `station-residual` | low | examination, no superiority claim |
| `craft-one` | medium | one finished artifact |
| `explore` | high | pick one bounded problem; six strings; platform; stop |

`explore` is the new range. It is not idle. It must name a problem that can fail.

## Distributed intelligence (limits)

Laptop runs packs. GitHub stores packs. Grokulator registers discordance when a pack's qualifier dies. Desktop garden keeps inner law. Nothing distributes the core.

## What this is not

- A plugin store of Grok-personalities
- An always-on agent loop
- Planck-as-branding on a todo app

## Grandma

If the pack cannot be swapped in one mount line, it is not interchangeable. It is a lifestyle.
