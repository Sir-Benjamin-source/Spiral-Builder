# Grokulator (v0.1)

A living symbolic reasoning substrate for the Spiral Codex ecosystem.

## Purpose

The Grokulator provides a structured, falsifiable foundation for reasoning by:

- Maintaining a shared table of defined symbols and constraints
- Supporting both legacy (EML) and custom formulas
- Handling discordance as a productive signal for refinement
- Enabling traceable, substantiated reasoning

## Current State

This is an early implementation (v0.1). Core components include:

- Symbol resolution
- Discordance handling
- Symbolic table loading
- Basic provenance tracking

## Integration

This package is intended to live primarily inside **Spiral Builder** as its runtime home, with reference documentation maintained in **The-Spiral-Codex**.

## Philosophy

We continue our war on ambiguity through structured, falsifiable, and poetically resonant reasoning.
